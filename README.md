# 🧮 Advanced CLI Calculator (Go)

Консольный калькулятор, написанный на языке Go. Проект создан в учебных целях для портфолио и демонстрирует применение принципов **Чистой Архитектуры (Clean Architecture)**, обработку ошибок и работу с вводом/выводом без использования сторонних библиотек.

## 🚀 Возможности

*   **Базовые операции:** сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`).
*   **Продвинутые операции:** возведение в степень (`^`), остаток от деления (`%`).
*   **Умное форматирование:** вывод результата с помощью спецификатора `%g` (отсекает лишние нули, использует научную нотацию при необходимости).
*   **REPL (Read-Eval-Print Loop):** бесконечный цикл для многократных вычислений.
*   **Обработка ошибок:** защита от деления на ноль и некорректного ввода (буквы вместо цифр). Программа не падает, а просит ввести данные заново.
*   **История операций:** сохранение и вывод последних 5 успешных вычислений (команда `history`).
*   **Удобный выход:** команды `exit` или `q` для завершения работы.

## 🏗️ Архитектура проекта

Проект разделен на слои по принципам Чистой Архитектуры. Зависимости идут строго внутрь (от интерфейса к бизнес-логике):

```text
calculator/
├── cmd/
│   └── calculator/
│       └── main.go          # Точка входа, сборка зависимостей (Dependency Injection)
├── internal/
│   ├── domain/              # Сущности (Entities) - не зависят ни от чего
│   │   └── operation.go     # Структура данных операции
│   ├── usecase/             # Бизнес-логика (Use Cases) - математика и проверки
│   │   └── math_usecase.go  
│   └── delivery/            # Слой доставки (Interface Adapters)
│       └── console/
│           └── handler.go   # Работа с консолью, ввод/вывод, валидация строк
├── go.mod
└── README.md
